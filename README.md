# Roshni — PM Portfolio

Dark editorial portfolio site for a Product Lead specialising in compliance-as-growth, fintech, and risk platforms.

## Stack

- Vanilla HTML/CSS/JS — single file, no build step
- GSAP 3.12.5 + ScrollTrigger (CDN)
- Canvas 2D — product network graph + bokeh particles
- Google Fonts — Cormorant Garamond + DM Sans

## Features

- Compliance-inspector loading screen
- Cinematic video hero (plays once, sound-first, pauses on scroll)
- Product network graph: Growth / Risk / Platform / Ops / Trust
- Light / dark mode toggle with localStorage persistence
- GSAP scroll-reveal animations throughout

## Deploy

Deployed via Vercel. `vercel.json` handles SPA-style routing.
